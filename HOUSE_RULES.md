# House rules

These rules apply to every change in this repository (code, copy, commits, logs, and pull request text).

## Pull requests and git

- Open **draft PRs only**. Never merge, never force-push, and never push to `main`.
- Use **small commits** with clear messages.

## Secrets and infrastructure

- **No secrets** in code, commits, logs, or PR text: keys, tokens, RPC URLs, wallet keys, phone numbers, and similar values belong in environment configuration only.
- **Nothing on our bot server.** No real money and no mainnet sends.
- If a task needs payment, a card, or KYC, **stop and report** — do not sign up.

## Public identity and copy

- **Public names only:** “Wyndham Heaven” (person) and “elghaly” (brand). Do not use a legal name anywhere in public-facing material.
- **No street addresses, cities, or countries** on any public page. Remove any that already exist.
- **Contact line** (exact wording on public pages):

  `Email first: support@elghaly.dev. Calls by appointment.`

## Banned visible words

The following must **not** appear in user-visible text (any case). Use the suggested alternatives when needed:

| Avoid | Prefer |
| --- | --- |
| live | running |
| profit | results |
| guarantee | promise |
| audit | review |
| launched | released |
| only | (reword the sentence) |
| trading | (reword, e.g. "copy-mirroring") |

## Content preservation

- **Keep all existing content** unless a task explicitly asks to remove it.

## Agent checklist before finishing

- Draft PR link
- Test output
- Screenshots at **390px** and **1280px** width
- List anything that could not be done and why
